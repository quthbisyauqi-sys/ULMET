📄 Buka Dokumen di Google Docs

Google Docs membuka lembar baru kosong karena Google belum memuat file lokal Anda. Ada 2 cara mudah memunculkan isinya:

Cara 1 (Paling Cepat - Tempel):

Teks dan format dokumen ini sudah otomatis disalin ke clipboard. Di Google Docs yang baru terbuka, cukup tekan Ctrl + V (Paste). Seluruh isi dokumen langsung muncul rapi!

Cara 2 (Buka Berkas Word .docx):

Di tab Google Docs, tekan Ctrl + O (atau menu File ➔ Buka) ➔ pilih tab Upload ➔ pilih berkas Word Anda.

Kirim File dari WhatsApp ke ULMET

Dosen sering mengirim materi perkuliahan (PDF, Word, PPT) di grup WhatsApp? Anda bisa langsung mengirimnya ke ULMET tanpa perlu download lalu upload manual:

1
Install ULMET di HP: Pastikan aplikasi ULMET sudah ditambahkan ke layar utama (*Add to Home Screen*) dari Chrome Android/iOS.
2
Buka File di WhatsApp: Ketuk berkas dokumen di WhatsApp, lalu tekan tombol Bagikan / Share (ikon tiga titik/tanda panah).
3
Pilih Aplikasi ULMET: Dari daftar aplikasi share di HP Anda, pilih ULMET.
4
Simpan ke Folder Matkul: ULMET otomatis terbuka dan Anda tinggal memilih folder mata kuliah tujuan. Berkas langsung tersimpan rapi!
