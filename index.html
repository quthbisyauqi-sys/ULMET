Fitur & Nilai Inovasi

Dirancang Spesifik Menyelesaikan Problematika Mahasiswa

Kombinasi fitur terintegrasi yang menjawab tuntutan akademik, manajemen finansial, serta kesejahteraan mental mahasiswa.

📥

WhatsApp Web Share Target 2.0

Dosen kirim modul atau slide di WhatsApp? Mahasiswa cukup klik Share dari HP dan pilih ULMET. Berkas seketika terklasifikasi ke folder mata kuliah lokal tanpa takut link kedaluwarsa.

✓ Inovasi Web API PWA Terkini
🤖

AI ULMET Pembaca PDF Modul

Didukung multi-model LLM modern dan engine PDF.js langsung di peramban. Mampu merangkum bab tebal perkuliahan, menyusun flashcards ujian, dan membuat kuis latihan mandiri.

✓ Multi-Model AI Ingestion
🎭

Maskot Gamifikasi Emosional ("Si Ulmet")

Karakter maskot hidup yang ekspresinya berubah adaptif sesuai ketuntasan tugas: Reward Mood (bangga), Worried Mood (deadline mepet), dan Angry Mood (tugas menumpuk) untuk mencegah prokrastinasi.

✓ Pendekatan Behavioral Psychology
💸

Kalkulator Jatah Kos & Patungan

Menghitung otomatis jatah batas belanja harian yang aman agar uang bulanan tidak ludes di awal bulan. Dilengkapi pelacak patungan kos dan tabungan impian berjangka.

✓ Literasi Finansial Mahasiswa
⚡

100% Local-First & Bebas Server

Seluruh basis data (akun, profil, jadwal, keuangan) dan file biner tersimpan di memori perangkat mahasiswa via IndexedDB. Nol biaya langganan cloud dan bebas risiko server down.

✓ Zero Operational Maintenance
🔔

Push Notification Deadline Daemon

Ditenagai Service Worker background yang bekerja layaknya aplikasi native Android APK. Tetap dapat mengirimkan alarm pengingat tugas kuliah meski tab browser sedang ditutup.

✓ Standalone PWA Architecture
Dampak & Solusi Nyata

Kekacauan Mahasiswa vs Ekosistem ULMET

❌ Tanpa ULMET (Kekacauan Rutin)
  • • Materi kuliah PDF di grup WhatsApp tertimbun ribuan chat dan link unduhan kedaluwarsa.
  • • Tugas terlupakan hingga H-1 jam deadline; sering begadang sistem kebut semalam (SKS).
  • • Uang bulanan kos habis di minggu kedua karena tidak ada perhitungan batas aman belanja harian.
  • • Portal kampus sering error / tidak bisa dibuka saat sinyal di kelas lemah.
✅ Dengan ULMET (Ekosistem Terintegrasi)
  • • Cukup tekan Share di WhatsApp, materi kuliah seketika tersimpan rapi per mata kuliah di memori lokal.
  • • Maskot "Si Ulmet" dan alarm background aktif mengingatkan jadwal jauh sebelum deadline tiba.
  • • Kalkulator cerdas otomatis memberi rekomendasi pengeluaran harian agar uang saku bertahan sebulan penuh.
  • • 100% Offline-Ready; jadwal dan materi kuliah terbuka seketika dalam 0ms tanpa kuota internet.
Inovasi Berkelanjutan

Mengapa Arsitektur ULMET Ramah Masa Depan?

Menjawab tema INVOFEST "Digital Solutions for a Sustainable Future", ULMET memutus ketergantungan pada server cloud terpusat yang boros konsumsi energi dan berbiaya mahal.

🌱 Zero Carbon & Energy

Mengeliminasi beban komputasi server cloud yang terus menyala 24 jam dengan mendistribusikan penyimpanan di perangkat masing-masing pengguna.

💰 Zero Operational Budget

Tidak membutuhkan donasi atau tagihan server bulanan. Aplikasi dapat terus beroperasi secara mandiri sepanjang masa studi mahasiswa.

🛡️ Impenetrable Privacy

Bebas risiko kebocoran data terpusat (*zero central data leak*) karena data keuangan dan berkas tersimpan privat di laptop mahasiswa.
